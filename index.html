    Step-by-step guide

    Run your pageant tabulation

    Follow these steps in order. Use each button to open the screen for that step.

    1. Enter event details

      Add the pageant name, date, and location.

    2. Add contestants

      Give every contestant a unique entry number and name.

    3. Add judges

      Create one record for each person who will score.

    4. Set up rounds, categories, and criteria

      Use Quick setup to add several stages and scoring categories together. Set their order and how many contestants advance, then review the weight changes before saving. On Categories, use Round to edit to manage one round at a time. Later rounds stay locked until every previous round is finished.

    5. Enter scores

      Select a round, category, and criterion. Enter all judges’ scores for each contestant. Choose Save & view rankings to open Results for that round, or Save & next to continue to the next grid. Results keeps each round in its own section.

    6. Finish a round and advance contestants

      After reviewing Rankings for this round, check What is missing and resolve any cutoff tie. Choose Finish round & proceed to next to finish this round and open judging for the next round with only the advancing contestants.

    7. Back up and share results

      Download a JSON backup. From Results, print a tabulation sheet or export CSV files.
